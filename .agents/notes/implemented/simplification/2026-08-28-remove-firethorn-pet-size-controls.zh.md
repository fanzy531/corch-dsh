# Agent Note: 移除火棘宠物的大小控制

Status: implemented

[English](2026-08-28-remove-firethorn-pet-size-controls.md) | 中文

## Problem

浮动火棘宠物只需要提供稳定、低干扰的校园 AI 陪伴。大小控制会增加可见界面和呈现状态，但没有支持其他产品行为。

## Decision

宠物以包定义的 `144px` 正方形渲染，不提供大小控制。`PetState` 只包含停靠边和沿边归一化偏移量；`dsh.firethorn-pet.v1` 只持久化位置。组件、几何计算、样式表、导出、测试、包描述和 README 均描述固定大小的呈现方式。

## Alternatives considered

**保留大小控制** —— 否决，因为宠物的呈现职责不需要额外操作入口和持久化偏好。

**隐藏按钮但保留 scale 状态** —— 否决，因为这会保留未使用的状态，并让已移除的行为继续存在于公共客户端类型和持久化解析器中。

**使用响应式大小** —— 否决，因为视口相关的尺寸会降低角色视觉识别的一致性，同时没有解决明确的产品需求。

## Consequences

组件拥有一个可预测的视觉占用空间，浏览器状态记录也更小。带有无关额外 JSON 字段的既有位置数据会被解析为位置记录；本包不会保留或迁移大小偏好。重新引入用户可选大小需要新的交互和状态决策。

## Verification

几何、状态和组件聚焦测试验证固定大小定位、仅位置持久化以及没有额外控制按钮。包构建和 TypeScript 检查覆盖更新后的导出和运行时路径。
